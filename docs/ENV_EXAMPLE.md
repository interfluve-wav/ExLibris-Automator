# Environment Example

Copy these into a `.env` file in the project root and set the values.

# Required
OPENAI_API_KEY=sk-prod-...
CITATION_PARSER=openai
ESPLORO_USERNAME=
ESPLORO_PASSWORD=
DISCORD_BOT_TOKEN=

# Optional
OPENAI_MODEL=gpt-4o-mini
DEFAULT_RESEARCHER=Scarano, Frank J
# CITATION_CHANNEL_ID=123456789012345678
#   Restricts the bot to one channel. To get this ID:
#   Discord → User Settings → Advanced → enable Developer Mode
#   Right-click your channel → Copy Channel ID
# DISCORD_GUILD_ID=123456789012345678
#   Speeds up slash command registration by syncing to a specific server (guild)
#   To get this ID: Right-click the server icon → Copy Server ID (Developer Mode on)
DISCORD_WEBHOOK_URL=
NOTIFICATION_EMAIL=
